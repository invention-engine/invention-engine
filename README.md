# RPG Engine (Aerthos Edition)

A Web-Based 3D Open-World RPG Skeleton designed to consume procedural JSON data from the World Generator and dynamically construct a navigable, lore-accurate 3D world without manual authoring.

## 🌟 Vision

To build a deterministic, procedural 3D game engine that translates raw geographic, geopolitical, and narrative data (JSON) into a living, breathing world. This engine acts as the runtime environment for the **Invention Engine** ecosystem.

## 🏗️ Architecture

### 1. The Spatial Grid

Transforms 1D array heightmaps and Voronoi coordinates into a 3D terrain mesh using Three.js.

### 2. Asset Ingestion Pipeline

Maps JSON cultural properties to 3D runtime behaviors, tinting terrain shaders, spawning specific flora meshes, and adjusting atmospheric lighting based on the assigned culture and creation myths.

### 3. Gameplay Engine

Translates lore and traditions into interactive gameplay loops (e.g., dynamically spawning 'Spirit-Hunting' quests based on the Wildlands cultural values).
